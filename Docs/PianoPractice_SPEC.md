# ピアノ練習アプリ 仕様書（B案「五線ガイド」ベース）

> Claude Code への実装依頼用。デザインの元はデザインキャンバス「ピアノ練習アプリ — ラフ案」の **B案 五線ガイド**。
> 寸法・色はこのキャンバスから起こしたもの。迷ったらキャンバスを正とする。

---

## 1. 目的

楽譜（MusicXML）を読み込んで、iPad でピアノを練習するための個人用アプリ。

一番解決したいのは **「譜面の音」と「鍵盤の位置」の対応にワンクッションかかる（"えーっと、E はここ…"）** こと。そのために:

- 上段：普通の譜面（大譜表）に現在位置を示す
- 中段：これから弾く鍵盤を、上から下へ落ちてくるノーツで知らせる（ビートマニア／Synthesia 型）
- 下段：鍵盤
- **落下レーンに「五線」を縦線として通す。** ト音記号の5本線（E4 G4 B4 D5 F5）とヘ音記号の5本線（G2 B2 D3 F3 A3）の鍵盤位置に色付きの縦線を引く。これで「譜面で線の上の音は、レーンでも線の上を落ちてくる」状態にし、譜面・レーン・鍵盤を一本の線でつなぐ。

これがアプリの核。ほかの機能はこの体験を邪魔しないことを優先する。

---

## 2. 対象・技術

| 項目 | 内容 |
|---|---|
| 端末 | iPad（主）。横向き固定。基準は 11インチ 1194×834pt |
| 将来 | Mac（Mac Catalyst か マルチプラットフォーム SwiftUI）。初期は考慮だけしておく |
| UI | SwiftUI |
| 描画 | 譜面・レーン・鍵盤は SwiftUI `Canvas` ＋ `TimelineView(.animation)` で毎フレーム描く。View を音符の数だけ並べない |
| 音 | `AVAudioEngine` ＋ `AVAudioUnitSampler`（ピアノの SoundFont／EXS を同梱するか、GM の内蔵音色） |
| MIDI入力 | CoreMIDI（USB／Bluetooth MIDI キーボード）。打鍵判定に使う |
| ファイル | MusicXML（`.musicxml`、`.xml`、圧縮版 `.mxl`）。Files アプリから読み込む（`fileImporter`）。共有シートからも受け取る |
| 外部ライブラリ | なるべく使わない。MusicXML は `XMLParser` で必要な範囲だけ自前でパースする。`.mxl` の解凍には ZIP ライブラリ（ZIPFoundation など）を1つだけ許可 |

## 3. 画面構成（1194×834pt）

上から4段。

| 領域 | y範囲（pt） | 高さ | 内容 |
|---|---|---|---|
| トップバー | 0–56 | 56 | 戻る／曲名・メタ情報／先頭へ／再生／テンポ／手の切替／五線ガイド切替／ループ範囲 |
| 譜面 | 56–304 | 248 | 大譜表（現在は4小節分を表示）。現在小節ハイライト、再生位置線 |
| 落下レーン | 304–684 | 380 | 6拍ぶんを先読み表示。五線ガイド、拍線・小節線、落下ノーツ |
| 鍵盤 | 684–834 | 150 | 横幅いっぱいの鍵盤（初期範囲 G2–C6、白鍵25） |

画面サイズが変わる場合は、譜面とレーンの高さ比を保ったまま伸縮させる。鍵盤の高さは 150pt 固定（最小 120pt）。

### 3.1 トップバー（高さ56、左右パディング16、要素間10）

左から:

1. **戻る**（44×44、角丸10、地 #F0F1F3）→ 曲ライブラリへ
2. **曲名**（15pt Bold）＋ メタ（11pt #5A606B）：`MusicXML · ハ長調 · 4/4 · 4小節`
3. スペーサ
4. **先頭へ**（44×44）
5. **再生／一時停止**（52×44、地 #1B1D21、白アイコン）
6. **テンポ**：`−`（44×44）｜`♩ = 80`＋小さく「原曲の67%」｜`＋`（44×44）。5% 刻み、25%〜150%
7. **手の切替**（セグメント）：右手／両手／左手。文字色は右手=青、左手=オレンジ、両手=墨。選択中は白地＋影
8. **五線ガイド**のトグル（オン／オフ）
9. **ループ**：アイコン＋「1–4小節」。タップで範囲を設定するシートを開く

タップ領域は全て 44pt 以上。

- 色は「右手=青、左手=オレンジ」を **譜面・レーン・鍵盤の全てで統一** する。ここがぶれると対応関係が崩れる
- 落下レーンのダーク表示は設定で切り替えられるようにする（デザインの Tweaks「darkLane」）

### 4.2 フォント

- UI：IBM Plex Sans JP（同梱）。なければヒラギノ角ゴ
- 音楽記号：SMuFL 対応フォント **Bravura** を同梱し、音部記号・拍子記号・臨時記号・休符を描く（デザインでは代用で Noto Music を使っている）
- 符頭・符幹・加線は `Canvas` のパスで描く

### 4.3 音名表記

設定で `CDE` と `ドレミ` を切り替える（デザインの Tweaks「naming」）。

- CDE：C C♯ D E♭ E F F♯ G A♭ A B♭ B
- ドレミ：ド ド♯ レ ミ♭ ミ ファ ファ♯ ソ ソ♯ ラ シ♭ シ
- 臨時記号の付いた音は、譜面の表記（♯か♭か）に合わせて名前を出す（MusicXML の `<alter>` に従う）
- C の鍵だけオクターブ番号を付ける（C3、C4…）。中央 C = C4（MIDI 60）

## 5. 譜面ビュー（y 56–304）

### 5.1 レイアウト

- 大譜表（ト音＋ヘ音）を1段で表示。現在は **4小節を横に並べる**
- 五線の間隔 `G = 11pt`（線と線の距離）、半間隔 `S = G/2`
- ト音譜表の第1線（E4）の y = 154、ヘ音譜表の第1線（G2）の y = 266（画面座標）
- 音高の y（全音階番号 `d` = オクターブ×7＋音名番号、C=0 … B=6。例：E4 = 30、G2 = 18）
  - ト音：`y = 154 − (d − 30) × S`
  - ヘ音：`y = 266 − (d − 18) × S`
- 横方向
  - 五線の左端 XL = 36、右端 XR = 1176
  - 1小節目の開始 X0 = 146、小節幅 `MW = (XR − X0) / 4`
  - 拍 b の x：`X0 + 18 + b × (MW − 26) / 4`
  - 実装時は、音価に応じた間隔（短い音符は詰める）を入れてもよい。ただし拍位置との対応は崩さない
- 左端：音部記号（XL+6）、拍子記号（X0 − 38）、調号はその間
- 小節番号：各小節の左上、11pt #8A909A
- 終止線：最終小節の右端に太線（3pt）

### 5.2 五線ガイドとの連動（B案の要）

- 五線の左端（x 14–32）に、**線ごとの音名** を小さく表示（10pt Bold）
  - ト音の5本：E G B D F を `handR` 色
  - ヘ音の5本：G B D F A を `handL` 色
- 譜面の五線そのものは墨色のまま（実際の楽譜と同じ見た目で読む練習になるように）
- 五線ガイドをオフにしたら、この音名表示も消す

### 5.3 音符の描画

| 要素 | 仕様 |
|---|---|
| 符頭 | 幅 1.32G × 高さ 0.92G の楕円、−18°回転。2分以上は中抜き（線幅 max(1.6, 0.16G)） |
| 符幹 | 長さ 3.4G、幅 1.4pt。ト音は d < 34（B4未満）で上向き、ヘ音は d < 22（D3未満）で上向き。上向きは符頭の右端、下向きは左端 |
| 旗・連桁 | 8分以下。連桁は拍単位でまとめる（MusicXML の `<beam>` があればそれに従う） |
| 付点 | 符頭の右 0.35G。線上の音なら半間隔上にずらす |
| 加線 | 譜表の外の音に、幅 = 符頭 + 0.8G |
| 臨時記号・休符・タイ | Bravura のグリフで描く |

**音符の状態と色**

| 状態 | 条件 | 色 |
|---|---|---|
| 弾き終わり | 終了 ≤ 現在 | `played` #B7BCC4 |
| 発音中 | 開始 ≤ 現在 < 終了 | 手の色＋外側に 0.35G の薄色ハロー |
| これから | 開始 > 現在 | `ink` |

### 5.4 現在位置

- **現在小節ハイライト**：小節の幅いっぱい、五線の上下に 1.6G はみ出す矩形、#FFF3C4、角丸6
- **再生位置線**：2pt、墨色、ハイライトと同じ高さ。上端に直径10の丸
- 再生位置線は拍位置の式で滑らかに動かす（フレーム単位で補間する）

### 5.5 スクロール（デザイン外・実装時に決めた仕様）

- 4小節を1ページとし、再生位置が4小節目の途中に来たら、次のページへ **横スライドで切り替える**（0.25秒）。譜めくりと同じ感覚にする
- 設定で「連続スクロール（再生位置を左から1/3に固定し、譜面が流れる）」も選べるようにしておく。初期値はページ切替

## 6. 落下レーン（y 304–684、高さ380）

### 6.1 時間軸

- **下端が判定ライン（今）**、上へ行くほど未来
- 先読みは **6拍**：`PPB（1拍あたりのpt）= レーン高 / 6`（380 / 6 ≈ 63.3）
- 開始 s、長さ d の音符：下端 y = `H − (s − now) × PPB`、上端 y = `H − (s + d − now) × PPB`（レーン内の座標、H = レーン高）
- 判定ラインより下の部分は切り取る（鳴っている音符は、判定ラインから伸びていて上から縮んでいく）
- 先読みの拍数は設定で 4〜8 拍に変えられるようにする

### 6.2 背景

1. 地：`laneBg`
2. 黒鍵の列：黒鍵と同じ x・幅で `laneBlackCol` の縦帯
3. 拍線：1pt `beatLine`。小節線：2pt `barLine`。小節線の上に「n小節」ラベル（11pt Bold、左端 x=8）

### 6.3 五線ガイド（B案の要）

- 次の鍵の **中心** に縦線を引く（幅2pt、レーンの上端から下端まで）
  - ト音の線：E4 G4 B4 D5 F5（MIDI 64 67 71 74 77）→ `handR`、不透明度 0.55（ダーク時 0.8）
  - ヘ音の線：G2 B2 D3 F3 A3（MIDI 43 47 50 53 57）→ `handL`、同上
  - 真ん中のド（C4 / MIDI 60）：2pt の **点線**、#9AA0A8（加線を表す）
- 縦線は落下ノーツより **手前に描く**。線上の音のノーツには線が貫いて見え、「線の上の音」だと分かる
- レーン上端（y=6）に各ガイド線の音名を表示（11pt Bold、線と同じ色）
- 凡例（レーン左下、白い半透明の札）：「━ ト音記号の5本線 ／ ━ ヘ音記号の5本線 ／ ┅ 真ん中のド（加線）／ 線の上に落ちる音＝譜面でも線の上」
- トップバーのトグルで表示／非表示
- 将来：五線の外（加線の音）がよく出る曲向けに、加線位置の点線（A5、C6、E2 など）を自動で追加するオプション

### 6.4 落下ノーツ

| 項目 | 仕様 |
|---|---|
| 位置 | 鍵の中心に合わせる |
| 幅 | 白鍵：KW − 10、黒鍵：BW − 6 |
| 高さ | 長さ × PPB − 3（同じ音が続いても隙間で区切れるように） |
| 角丸 | 7pt |
| 色 | 手の色（右=青、左=オレンジ） |
| 発音中 | 外側に 3pt の薄色リング（tintR / tintL） |
| ラベル | 高さ22pt以上のノーツは、下端に音名（13pt Bold、白）。CDE／ドレミ設定に従う |

### 6.5 その他の表示

- **判定ライン**：レーン下端に 3pt、墨色（ダーク時は白）
- **「次」チップ**（レーン右上、白地・角丸10・影）：「次」＋次に弾く音（同時に複数あれば全部）を手の色のピルで表示。例：`次 [G4]`。音名は「音名＋オクターブ」
- **手の凡例**：右手=青、左手=オレンジ（凡例の札に統合してよい）

## 7. 鍵盤（y 684–834、高さ150）

### 7.1 範囲と寸法

- 初期範囲は **G2–C6**（白鍵25本）。曲の最低音・最高音から、前後に余白を1〜2音とって自動で決める。最小でも3オクターブ表示し、最大は 88 鍵
- 白鍵幅 `KW = 画面幅 / 白鍵数`、黒鍵幅 `BW = 0.6 × KW`、黒鍵の長さ 92pt
- 黒鍵の中心 = 左隣の白鍵の中心 + KW/2（簡易配置。実物に近い偏りは後で入れてもよい）
- レーンの x 座標と鍵盤の x 座標は **必ず同じ関数** から出す（`keyCenterX(midi)`）

### 7.2 白鍵

- 地は白、右に 1pt の境界線 #C9CDD3、下の角丸6
- 下端に音名（13pt）。C は墨色の Bold＋オクターブ番号、その他は #6B717C
- **真ん中のド（C4）**：音名の上に直径6の灰色の点
- **五線の線の鍵の印**（B案）：ト音の5本線とヘ音の5本線にあたる白鍵の上端に、高さ6pt の色帯（左右に5ptずつ余白、下の角丸3）。ト音=青、ヘ音=オレンジ。五線ガイドのオン／オフに連動

### 7.3 鍵の状態

| 状態 | 白鍵 | 黒鍵 |
|---|---|---|
| 通常 | 白、音名グレー | 墨 |
| 予告（1拍以内に弾く） | 薄色（tint）＋内側 3pt の手の色の枠、音名 Bold | #3A3E46＋内側 3pt の手の色の枠 |
| 発音中（譜面上） | 手の色で塗る、音名は白 Bold | 手の色で塗る |
| 実際に押した | （MIDI入力時）押している間は少し沈んだ表現（上端に影）。正解なら手の色、違う鍵なら赤 #D92D20 で一瞬光らせる | 同左 |

## 8. 練習機能

### 8.1 再生

- 再生／一時停止、先頭へ
- テンポは原曲比で 25〜150%（5%刻み）。表示は「♩ = 80（原曲の67%）」の形
- 伴奏音：アプリが鳴らす音の音量は「右手／左手／メトロノーム」の3つで別々に設定する

### 8.2 手の切替（右手／両手／左手）

- **片手を選ぶと、もう片方の手はアプリが自動で演奏する**（音は鳴らす。ノーツは不透明度 0.35 で描き、判定はしない）
- 譜面では、練習しない手の音符を `played` 色に近いグレーで描く

### 8.3 正しい鍵まで待つ（待機モード）

- オン：判定ラインに来た音を正しく押すまで時間を止める。和音は全部押したら進む
- オフ：止めずに流す。判定（後述）だけ行う
- MIDI キーボードが無いときは待機モードを使えない（トグルを無効化し、理由を小さく表示する）

### 8.4 ループ

- 開始小節〜終了小節を指定してループ再生（初期は曲全体）
- 譜面の小節番号を長押し→ドラッグでも範囲を選べるようにする（将来）

### 8.5 打鍵判定（MIDI入力時）

- タイミングの許容幅：±120ms を「OK」、それより外は「早い／遅い」（値は設定で調整できるようにする）
- 判定結果は、落下ノーツが判定ラインで消えるときに短く表示する（OK は手の色で光る、ミスは赤い縁）
- 1回の通し練習ごとに「正確さ ◯%」を記録する（履歴画面は範囲外。データだけ残す）

### 8.6 MIDI 入力が無いとき

- 画面の鍵盤をタッチして弾けるようにする（同時押し対応）。判定はタッチ入力でも同じに行う
- マイクでの音程判定は範囲外（将来の候補）

## 9. MusicXML 読み込み

### 9.1 対応範囲（初期）

| 要素 | 扱い |
|---|---|
| `score-partwise` | 対応。`score-timewise` は範囲外 |
| `part` | 最初のピアノパート（`staves`=2 のパート）を使う。無ければ最初のパート |
| `staves` / `staff` | staff 1 = 右手、staff 2 = 左手。staff が1つしかない場合は全部右手扱い（C4 で分ける自動振り分けはオプション） |
| `divisions` | tick 換算に使う |
| `note` / `pitch`（step, alter, octave） | 対応 → MIDI ノート番号 |
| `rest` | 対応（譜面に描く。レーンには出さない） |
| `chord` | 対応（直前の音と同時） |
| `duration` / `type` / `dot` | 対応 |
| `tie`（start/stop） | 対応。レーンでは1本の長いノーツにまとめる |
| `backup` / `forward` | 対応（複数声部） |
| `voice` | 読み込むが、描画は声部を区別しない（符幹の向きだけ参考にする） |
| `time` / `key` / `clef` | 対応（途中変更も） |
| `sound tempo` / `metronome` | テンポの初期値。無ければ ♩=120 |
| `beam` | 連桁の描画に使う |
| `fingering` | 読み込んで保持（表示は将来） |
| 繰り返し記号・ダ・カーポ | 初期は無視（書かれている順に並べる）。将来は展開に対応 |
| `grace`（装飾音） | 初期は無視 |

- `.mxl` は解凍して `META-INF/container.xml` が指す本体を読む
- 読み込めない要素があっても止めずに読み込み、読み飛ばした内容を画面に一度だけ通知する

### 9.2 曲ライブラリ

- アプリ内の Documents に読み込んだ曲をコピーして一覧表示（曲名、作曲者、小節数、最後に練習した日）

## 10. データモデル（Swift の叩き台）

```swift
struct Score {
    var title: String
    var composer: String?
    var ticksPerQuarter: Int          // 例: 480
    var tempoBPM: Double              // 原曲テンポ
    var measures: [Measure]
    var notes: [Note]                 // 全音符を開始tick順に
}

struct Measure {
    var index: Int                    // 0始まり
    var startTick: Int
    var lengthTicks: Int
    var time: TimeSignature           // 4/4 など
    var key: KeySignature             // fifths
    var clefs: [Int: Clef]            // staff番号 → 音部記号（変更がある小節のみ）
}

enum Hand { case right, left }

struct Note: Identifiable {
    let id: UUID
    var startTick: Int
    var durationTicks: Int            // タイ結合後の長さ（レーン用）
    var midi: Int                     // 60 = C4
    var step: Character               // C D E F G A B
    var alter: Int                    // -1 / 0 / +1
    var octave: Int
    var hand: Hand                    // staff 1 = right, 2 = left
    var staff: Int
    var voice: Int
    var noteType: NoteType            // whole, half, quarter, eighth...
    var dots: Int
    var tieStart: Bool
    var tieStop: Bool
    var isRest: Bool
    var fingering: Int?
}

struct PracticeSettings: Codable {
    var tempoRatio: Double = 1.0      // 0.25...1.5
    var hands: HandsMode = .both      // .right / .both / .left
    var waitForCorrectKey = true
    var loopRange: ClosedRange<Int>?  // 小節番号
    var lookaheadBeats: Double = 6
    var showStaffGuides = true
    var naming: Naming = .cde         // .cde / .doremi
    var darkLane = false
}
```

座標計算は1か所にまとめる（`LayoutMetrics`）。

- `keyCenterX(midi:) -> CGFloat`（レーンと鍵盤で共用）
- `staffY(diatonic:hand:) -> CGFloat`
- `beatX(beat:) -> CGFloat`（譜面）
- `laneY(tick:now:) -> CGFloat`（レーン）

## 11. 実装ステップ

各ステップの最後に確認条件を置く。

1. **鍵盤とレーンだけ（ハードコードの曲）**
   - 「歓喜の歌」冒頭4小節（デザインの仮データ）をコードに直書きし、落下ノーツ・五線ガイド・鍵盤の状態表示を 60fps で動かす
   - ✅ ノーツの中心と鍵の中心が全ての鍵で一致する。五線ガイドがノーツを貫いて見える
2. **譜面ビュー**
   - 大譜表、音符の状態色、現在小節ハイライト、再生位置線、ページ切替
   - ✅ 再生位置線が拍位置と一致し、落下ノーツが判定ラインに着くのと同時に譜面の音符が「発音中」の色になる
3. **音を鳴らす**
   - AVAudioUnitSampler で再生。テンポ％、手の切替（片手は自動演奏）
4. **MusicXML 読み込み**
   - 9.1 の範囲。Files から読み込み、曲ライブラリ
   - ✅ MuseScore から書き出した2段譜（右手・左手）が崩れずに表示される。タイが1本のノーツになる
5. **MIDI 入力と判定**
   - CoreMIDI、待機モード、判定表示、画面鍵盤のタッチ入力
6. **仕上げ**
   - 設定画面（音名表記、先読み拍数、ダークレーン、判定幅）、曲ごとの設定保存、ループ範囲指定
