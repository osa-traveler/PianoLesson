# 操作方法・仕様

アプリの使い方と、実装済みの仕様をまとめる。デザインの元になった仕様は [PianoPractice_SPEC.md](PianoPractice_SPEC.md) にある。この文書は「いまのアプリが実際にどう動くか」を書く。仕様と違う点は最後の章にまとめた。

---

## 1. 曲ライブラリ

起動すると曲の一覧が出る。内蔵サンプルとして「歓喜の歌」（4小節）が入っている。

| 操作 | 方法 |
|---|---|
| 曲を開く | 行をタップ |
| 曲を読み込む | 右上の「MusicXML を読み込む」から Files で選ぶ（複数選べる）。または、ほかのアプリの共有メニューで「ピアノ練習」を選ぶ |
| 曲を削除 | 行を長押しして「削除」（内蔵サンプルは消せない） |

- 対応形式：`.musicxml`、`.xml`、`.mxl`（圧縮版）
- 読み込んだファイルは、アプリ内（Documents/Songs）にコピーして持つ
- 一覧には、曲名・作曲者・小節数・最後に練習した日・直近の正確さを表示する
- 読み飛ばした内容があれば、読み込んだときに1回だけ通知する（例：パートが複数ある、装飾音、繰り返し記号、拍子と長さが合わない小節）

## 2. 練習画面

上から4段。

```
┌ トップバー ─────────────────────────────────────┐
│ 譜面（大譜表、4小節ずつ）                          │
│ 落下レーン（下端が「今」。上から音が落ちてくる）       │
│ 鍵盤                                              │
└──────────────────────────────────────────────┘
```

### 2.1 トップバー

左から：

| ボタン | 動作 |
|---|---|
| ‹ | ライブラリへ戻る（設定と位置を保存する） |
| ⏮ | ループの先頭（の1小節前）へ戻る |
| ▶ / ⏸ | 再生／一時停止 |
| − ♩=80 ＋ | テンポ。原曲比 25〜150%、5% 刻み |
| 右手／両手／左手 | 練習する手。片手を選ぶと、もう片方はアプリが自動で演奏する |
| 五線ガイド | 五線ガイドの表示／非表示 |
| 待つ | 待機モード（正しい鍵を押すまで止まる）。MIDI キーボードが無いと押せない（「MIDIなし」と出る） |
| ⚙ | 設定（下の表） |
| ⟳ n–m小節 | ループ範囲。開始小節と終了小節を指定する。「曲全体」で解除する。範囲を指定している間は青くなる |

**設定（⚙）**

| 項目 | 内容 | 初期値 |
|---|---|---|
| MIDI キーボード | つながっている機器の名前。「Bluetooth MIDI を接続…」で Bluetooth 機器を探す | — |
| 音名 | C D E ／ ド レ ミ | C D E |
| 先読み | レーンに表示する拍数（4〜8） | 6 拍 |
| レーンを暗くする | 落下レーンをダーク表示にする | オフ |
| 判定の幅 | ±50〜250ms | ±120ms |
| 音量 | 右手／左手／メトロノーム | 0.8／0.8／0.5 |
| メトロノーム | オン／オフ | オン |
| 弾いた音をアプリで鳴らす | MIDI や画面の鍵盤で弾いた音を鳴らす。音の出る電子ピアノならオフにする | オン |
| 練習する手もお手本の音を鳴らす | 練習している手の音もアプリが鳴らす。自分で弾くときはオフにする | オン |

設定・テンポ・手・ループ範囲・最後の位置は、曲ごとに保存する。

### 2.2 譜面

**譜面に触れて再生位置を変える**

| 操作 | 動作 |
|---|---|
| タップ | 触れた位置へ移動する |
| ドラッグ | 再生位置線が指についてくる。落下レーンと鍵盤も同じ位置に追従する |
| ページの右端より外へドラッグ | 次の小節へ進む（指を離すとそのページに切り替わる） |

- ドラッグ中は表示するページを固定する
- 落下レーンを上下にドラッグしても動かせる（2.3 節）
- 指を離すと、一番近い拍（拍子記号の1拍）にそろえる
- 再生中に触れると一時停止し、離すとそこから再生を続ける
- ループ範囲を指定しているときは、その範囲（と助走の1小節）の中だけ動かせる

- 大譜表（ト音記号とヘ音記号）を4小節ずつ表示する。再生位置が次のページの最初の小節に入ると、0.25 秒で横にスライドして切り替わる
- 音符の色：弾き終わり＝グレー、発音中＝手の色（右手は青、左手はオレンジ）＋薄いハロー、これから＝黒。練習しない手の音符は薄いグレー
- 現在の小節は黄色でハイライトし、再生位置を縦線で示す
- 五線ガイドがオンのとき、五線の左端に線ごとの音名（ト音＝E G B D F、ヘ音＝G B D F A）を出す
- 拍子記号は最初のページと、拍子が変わったときだけ出す。音部記号と調号は毎ページ出す

### 2.3 落下レーン

- 下端の太線が判定ライン（今）。上へ行くほど未来の音
- ノーツの色は手の色。発音中は薄色のリングが付く。高さが十分あるノーツには音名を表示する
- **五線ガイド**：ト音記号の5本線（E4 G4 B4 D5 F5）を青、ヘ音記号の5本線（G2 B2 D3 F3 A3）をオレンジの縦線で示す。真ん中のド（C4）は灰色の点線。線はノーツより手前に描くので、線の上の音は「線に貫かれたノーツ」として落ちてくる
- 右上の「次」：次に弾く音（同時なら全部）
- 「正確さ」：今回の通しで判定した音のうち、OK だった割合
- 判定ラインで、OK は手の色で光り、早い／遅い／ミスは赤い枠と文字で出る
- 待機モードで止まっている間は「正しい鍵を押すと進みます」と出る
- **上下にドラッグすると再生位置が動く**。ノーツが指についてくる向き（下へ引くと先へ進み、上へ引くと戻る）。レーンの1拍の高さぶんで1拍動く。軽く触れただけでは動かない。指を離すと拍にそろえ、再生中なら続きから再生する

### 2.4 鍵盤

- 表示範囲は曲の音域から自動で決める。G2〜C6 と五線ガイドの鍵は必ず含める
- 1拍以内に弾く鍵は、薄色＋手の色の枠（予告）。発音中は手の色で塗る
- 五線の線にあたる白鍵の上端に、色帯（ト音＝青、ヘ音＝オレンジ）
- 押している鍵は上端に影が付く。正しい鍵なら手の色、違う鍵なら赤（離すと 0.3 秒で消える）
- 画面の鍵盤はタッチで弾ける（同時押しに対応。指を滑らせると隣の鍵へ移る）

## 3. 練習の流れ

1. 曲を開く。前回の位置（その小節の1小節前）から始まる
2. ▶ で再生する。最初の1小節は助走（メトロノームのカウントイン）で、判定はしない
3. 弾く。MIDI キーボードがあればそれで、無ければ画面の鍵盤で
4. ループ範囲の最後まで行くと先頭へ戻る。そのとき、通しの正確さがライブラリに記録される（ループ範囲の最初の音から通したときだけ）

**待機モード**（MIDI キーボードが必要）：「待つ」をオンにすると、判定ラインに来た音を正しく押すまで止まる。和音は全部押したら進む。違う鍵では進まない。

## 4. MIDI キーボード

- USB：iPad につなぐだけで使える。設定の「MIDI キーボード」に名前が出る
- Bluetooth：設定 →「Bluetooth MIDI を接続…」で機器を選ぶ
- 判定は MIDI のタイムスタンプで行う
- 電子ピアノ自体の音とアプリの音が重なるときは、設定で「弾いた音をアプリで鳴らす」をオフにする

## 5. 判定

| 結果 | 条件 |
|---|---|
| OK | 音の開始から ±判定幅（実時間）以内に、正しい鍵を押した |
| 早い／遅い | 判定幅の外だが近い（判定幅の 2.5 倍まで。最低 ±0.35 秒）。正確さには数えない |
| ミス | 判定幅を過ぎても押されなかった |
| 違う鍵 | 近くにその鍵の音が無い。正確さには影響しない（鍵が赤く光るだけ） |

テンポを下げても、判定幅は実時間のまま変わらない。

## 6. MusicXML の対応範囲

| 要素 | 扱い |
|---|---|
| `score-partwise` | 対応（`score-timewise` は読み込めない） |
| パート | `staves=2` の最初のパート（ピアノ）を使う。無ければ最初のパート |
| 譜表 | staff 1 = 右手、staff 2 = 左手。1段しかなければ全部右手 |
| 音符・休符・和音・付点・タイ・連桁・符幹・臨時記号・指番号 | 対応（指番号は読むだけで、表示はしない） |
| `backup` / `forward`（複数声部） | 対応 |
| 拍子・調・音部記号 | 対応（途中の変更も。小節の途中での音部記号の変更は、その小節の頭で変わったとみなす） |
| テンポ | `sound tempo` と `metronome`。無ければ ♩=120 |
| 装飾音・繰り返し記号 | 無視する（繰り返しは展開せず、書かれた順に並べる） |
| 小節の長さ | 書かれた長さと拍子を比べる。長ければ書かれた長さにする。短ければ拍子の長さまで埋める（最初の小節と `implicit` の小節は弱起として短いまま） |

## 7. 仕様書との違い

| 項目 | 仕様書 | 実装 | 理由 |
|---|---|---|---|
| 譜めくり | 4小節目の途中で次のページへ | 次のページの最初の小節に入ったとき | 途中で切り替えると、弾いている小節が画面から消えるため |
| 連続スクロール | 設定で選べる | 未実装 | — |
| UI フォント | IBM Plex Sans JP を同梱 | システムフォント（ヒラギノ） | 未着手 |
| 鍵盤の範囲 | 曲の音域＋余白、最小3オクターブ | 曲の音域＋白鍵2本、さらに G2〜C6 を必ず含める | 五線ガイドの鍵が必ず見えるように |
| 画面の大きさ | 基準 1194×834（11インチ） | 13インチ（1376×1032）で、トップバーと鍵盤を固定し、残りを 248:380 で分ける | 実際に使う端末に合わせた |
| 待機モード中の自動演奏 | 記載なし | 止まっている拍の、練習しない手の音も、進むまで鳴らさない | 先に鳴るのを避けるため |

## 付録：開発用

### ビルド

```sh
cp Config/Local.xcconfig.example Config/Local.xcconfig   # DEVELOPMENT_TEAM を書く
./scripts/fetch-soundfont.sh                              # ピアノ音源（CC0）を取得
xcodegen generate
open PianoPractice.xcodeproj
```

ロジックのテスト：`cd Packages/PianoCore && swift test`

### 確認用の起動引数（DEBUG ビルドのみ）

| 引数 | 内容 |
|---|---|
| `-openSample YES` | 内蔵の曲を開く |
| `-scorePath <path>` | ファイルを直接開く |
| `-startBeat 5.5` | 位置（拍）を指定する |
| `-autoplay YES` | 再生を始める |
| `-hands left` | 手（right / both / left） |
| `-naming doremi` | 音名をドレミにする |
| `-darkLane YES` | レーンを暗くする |
| `-loop 1,2` | ループ範囲（小節 index） |
| `-demoPress 64,70` | 起動時にその鍵を押したことにする |
| `-demoScrubX 700` | 起動時に譜面のその x 座標までドラッグしたことにする |
| `-demoLaneDrag 160` | 起動時に落下レーンをその量（pt、下向きが正）だけドラッグしたことにする |
| `-noAudio YES` | 音を使わない（シミュレータで落ちるのを避ける） |

### コードの構成

```
App/                       iPad アプリ（SwiftUI）
  PianoPracticeApp.swift   ライブラリと練習画面の切り替え
  PracticeModel.swift      練習画面の状態（時計・判定・入力・音をつなぐ）
  Views/                   TopBar, ScoreCanvas, LaneCanvas, KeyboardCanvas, KeyboardTouchView, LibraryView
  Audio/AudioEngine.swift  Sampler・メトロノーム・発音スケジューラ
  MIDI/                    CoreMIDI 入力、Bluetooth MIDI の接続画面
  Library/SongLibrary.swift 曲の保存と一覧
Packages/PianoCore/        UI に依存しないロジック（テストあり）
  Model/      楽譜モデル（Score, Measure, Note, PlayNote）
  Timing/     TempoMap（拍⇄秒）、PracticeClock（ループ・ゲート付きの時計）
  Layout/     KeyboardLayout（keyCenterX をレーンと鍵盤で共用）、ScoreGeometry
  Engraving/  譜面の組版
  MusicXML/   読み込み、ZIP 解凍
  Practice/   設定、鍵の状態、発音の計画、判定
```
