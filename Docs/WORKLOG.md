## 2026-10-18 譜面のドラッグで再生位置を変える

- 実機で確認した結果：歓喜の歌が弾けた（音・入力とも動作）
- 譜面をタップ・ドラッグして再生位置を変えられるようにした。レーンと鍵盤も追従する
- 座標から拍への変換（`ScorePaging.beat(atX:)`）と拍へのそろえ（`snapToBeat`）は PianoCore に置き、テストを付けた
- 迷った点と決めたこと：
  - ドラッグの向き：紙を引っぱる向き（左へドラッグで先へ）ではなく、再生位置線を直接動かす向き（右へドラッグで先へ）にした
  - ページの扱い：ドラッグ中はページを固定する。ページの外へ引っぱれば次の小節へ進み、指を離すとページが切り替わる
  - 指を離したら拍にそろえる。音の途中から始まらないようにするため

## 2026-10-18（夜間）Phase 2〜7

### Phase 2：譜面ビュー（`0be6ca5`）

- 組版を PianoCore に分けた（`Engraving/Engraver.swift`）。和音のまとめ、符幹の向き、2度の符頭ずらし、臨時記号（調号と小節内の状態から決める）、連桁（`<beam>` を優先し、無ければ拍単位）、タイの対応付け。座標は持たず、拍位置と全音階番号で表す
- 座標は `ScoreGeometry`（仕様 5.1 の値を、パネルの大きさに合わせて伸縮）に集めた
- 4小節ごとの譜めくりと、0.25 秒の横スライド（`ScorePaging`）
- 描画は `ScoreCanvas`。音楽記号は Bravura のグリフを CoreText でパスにして描く
- 楽譜フォント Bravura（SIL OFL 1.1）をライセンス文書と一緒に同梱した

### Phase 4：MusicXML 読み込みと曲ライブラリ（`31995fc`）

- Phase 3 より先にやった。sample.mxl で譜面の描画を確かめたかったため
- `.mxl` の解凍は、外部ライブラリを使わず Compression フレームワークで自作した（無圧縮と deflate だけに対応）
- sample.mxl（OMR の出力）は、小節の長さが拍子と合わない、最初の小節に拍子記号が無い、などの不整合がある。それでも止まらずに読み、読み飛ばした内容を警告として1回だけ出すようにした
- 曲ライブラリ：Files からの読み込み、共有メニューからの受け取り、曲ごとの設定と最後の位置の保存
- テストには自作の短い曲（`Fixtures/test-piece.musicxml` / `.mxl`）を使う。sample.mxl は手元にあるときだけ読むテストにした

### Phase 3：音（`b063916`）

- ピアノ音源は FreePats「Upright Piano KW」（CC0）。56MB あるので git には入れず、`scripts/fetch-soundfont.sh` で取得する
- 右手と左手で Sampler を分け、メトロノームはクリック音を生成して鳴らす。音量は3系統で別々に設定できる
- 発音は専用キューの 5ms タイマーで行う。出力レイテンシのぶん早めに鳴らし、画面と揃える
- **問題**：iOS 26.5 シミュレータでは、AVAudioEngine に最初に触れたところで CoreAudio が「RPC timeout」になってアプリが落ちる。シミュレータを再起動しても直らず、Mac 本体では同じ処理が正常に動く。そこでシミュレータ側の問題と判断した
  - 対策として、オーディオの準備（セッション設定、グラフ構築、音源読み込み）をオーディオ用のキューに移した。結果は変わらなかったが、UI が待たされなくなったので、この形のまま残した
  - 出力レイテンシの問い合わせを 5ms ごとに行っていたのをやめ、キャッシュするようにした
  - シミュレータで画面を確認するために、DEBUG ビルドに `-noAudio YES` を追加した

### Phase 5：MIDI 入力・判定・待機モード（`6d74461`）

- 判定は `PracticeJudge`（PianoCore）。実時間（テンポ％で割り戻した秒）で ±判定幅なら OK、外なら早い／遅い。判定幅を過ぎても押されなければ見逃し
- 待機モードは、時計（`PracticeClock`）に「ゲート」を足して実装した。次に弾く拍で時計が止まり、正しい鍵がそろった瞬間に進み直す。ゲートは前もって置いておくので、行き過ぎてから戻ることはない
- 止まっている拍の自動演奏の音（練習しない手）は、進むまで鳴らさない
- MIDI は CoreMIDI の UMP（MIDI 1.0）で受け取り、パケットのタイムスタンプで判定する
- 画面の鍵盤は UIKit の小さなラッパーで、マルチタッチと指を滑らせての移動に対応した
- シミュレータでの確認用に `-demoPress` を追加した

### Phase 6：設定とループ範囲（`985cf64`）

- 設定ポップオーバー（表示・判定・音）と、ループ範囲のポップオーバー
